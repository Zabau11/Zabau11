# 💫 About Me:
Hi! I'm David, a first-year university student pursuing a Bachelor's in AI. I’m passionate about building practical, full-stack applications that solve real-world problems.
My first project was a "GPT Wrapper" designed to help real estate agents generate listing-ready images without needing a professional editor. Spoiler alert: it generated exactly $0 in revenue—but you live and you learn!
Onto the next one: I’m currently building my first AaaS (Agent as a Service) product, aiming to launch the MVP within the next two weeks.
I love exploring all corners of computer science, from AI and Machine Learning to core Web Development. In an industry that moves this fast, I believe the biggest mistake a developer can make is standing still.
